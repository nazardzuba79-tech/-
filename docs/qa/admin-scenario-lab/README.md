# Лаборатория: 10 сценариев симуляции

Рабочая реализация отдельного частного симулятора в `/admin/listings`.
Она НЕ управляет опубликованными лістингами и НЕ меняет сценарии NRX/VTA.

## Как открыть

Админка → Листинги → «Лаборатория: 10 сценариев симуляции».
Выберите «Автоматически по очереди» или один из десяти сценариев,
начальную условную цену, длительность 1/2/7 дней и необязательный код.
Нажмите «Создать пример». Интервалы: 15 минут / 1 час / 4 часа.
Ползунок показывает только первые выбранные часы примера; будущие свечи
не включены в OHLC. У неполной последней свечи есть явное пояснение.

## Десять вариантов

Спокойный тренд; импульсное движение; тренд с откатами; сжатие и пробой;
боковой диапазон; ложный пробой с возвратом; длинные тени; всплеск
волатильности и затухание; снижение и восстановление; стресс-сценарий.

Это разные гипотетические режимы, а не подгонка к обещанному росту.
Общей заданной конечной цены нет. Объём обозначает только модельную
активность в условных единицах, не реальные сделки.

## Сохранение и границы

- Свой `sessionStorage` ключ `voltex.admin.scenario-lab.v1`, максимум 20 примеров.
- Очередь локальна для вкладки браузера, не серверная и не общая между администраторами.
- Номер сценария и код сохраняются один раз. Обновление страницы их не меняет.
- Ручной выбор не сдвигает автоматическую очередь; после десятого следует первый.
- Изменение формы создаёт новый пример, не редактирует старую историю.
- Смена сессии очищает лабораторию. При недоступном хранилище ошибка показывается
  явно; сбой записи не расходует слот очереди.
- Нет новых API, запросов рыночных данных, таймеров, Worker или БД.
- Нет заявок, виртуального или реального кошелька: это лаборатория графиков,
  а не отдельный торговый движок. Данные никуда не публикуются.
- Существующие четыре профиля опубликованных рынков и все их конфигурации неизменны.
- Все названия, настройки, подсказки и сообщения лаборатории — по-русски.

## Модель

`listingScenarioModel.ts` — отдельный чистый модуль без импортов.
Версия 1, фиксированный код псевдослучайности, восемь внутриминутных
отсчётов цены на свечу, положительные OHLC, непрерывность open/close,
детерминированные тени и тела. 15/60/240 минут агрегируются из одного
минутного потока по UTC. Горизонт не переписывает ранее полученные свечи.
Новый математический алгоритм должен иметь новую версию.

## Проверки

Локально выполнена компиляция чистого модуля установленным TypeScript,
проверка десяти сценариев на непрерывность, стабильность префикса и
согласованность трёх таймфреймов. TSX прошёл синтаксическую транспиляцию;
это не проверка типов всего React-приложения.

Добавлены Jest-тесты модели, очереди, чтения недоверенных настроек и
границы импортов. Отдельный CI `Admin scenario laboratory (isolated, no trading)`
собирает реальный frontend и запускает browser QA на `/admin/listings`
при 1440/390 px: 11 автоматических назначений, ручной выбор, три интервала,
неизменность после reload, неверная цена, отсутствие запросов лаборатории,
переполнения страницы и финансовых записей. API — только локальные фикстуры,
внешние запросы и любые сетевые записи запрещены. Итоги и снимки — в CI artifact.

До получения результата exact-head CI проверки CI считаются ожидающими.
Production-админка с реальными учётными данными локально не проверялась.
