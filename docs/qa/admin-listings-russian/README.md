## Что действительно существует в проверенной базе

`simulationRealism.ts` содержит четыре профиля, а не десять.
`profileForOrdinal` назначает их циклически. `AdminListingsPage` показывает
профиль только для чтения; `configFromBody` не принимает его выбор из формы.
`withStableProfile` сохраняет уже присвоенный профиль при последующих правках.

Документ `docs/LISTINGS.md` также описывает связь опубликованных симулированных
рынков с обычными Spot-заявками. Поэтому текущий PR НЕ расширяет генератор
и НЕ добавляет управление траекторией опубликованной торговой пары.

## Предложение: 10 сценариев только для изолированного симулятора

Это проект следующего этапа, НЕ реализованные функции:

1. Спокойный тренд — небольшие разнонаправленные колебания.
2. Импульсное движение — отдельные движения с паузами.
3. Тренд с откатами — несколько волн и промежуточные коррекции.
4. Сжатие и пробой — сужение диапазона и выход из него.
5. Боковой диапазон — возвраты к середине без обязательного тренда.
6. Ложный пробой с возвратом — выход за диапазон и возврат.
7. Длинные тени — кратковременные отклонения от основных цен.
8. Всплеск волатильности и затухание — переход от резких колебаний к спокойным.
9. Снижение и восстановление — коррекция с последующим восстановлением.
10. Стресс-сценарий — затяжное снижение без обязательного восстановления.

Требования к будущей реализации:
- отдельное пространство тестовых данных и виртуальных балансов;
- видимая пометка «Симуляция» на всех демонстрационных графиках;
- запрет использовать этот источник для обычных ордеров, оценки реального
  баланса, ликвидаций, отчётности и подтверждения фактической ликвидности;
- «Автоматически по очереди» или ручной выбор только до запуска;
- присвоенный ID сохраняется один раз; перезагрузка не меняет сценарий;
- существующая история не переписывается;
- все названия, пояснения и ошибки в админке — по-русски;
- 15 минут, 1 час и 4 часа агрегируются из одного тестового потока;
- никаких обещаний заданной доходности или выдачи сгенерированного объёма
  за реальные сделки.
