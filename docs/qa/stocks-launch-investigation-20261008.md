## Data decision

No verified free license for publicly displaying commercial US 15-minute OHLCV on VOLTEX was found. Public display, client-facing JSON delivery, redistribution and historical retention must all be covered; a free endpoint or a "Commercial Use" pricing tick is insufficient.

First candidate: **Twelve Data Business Venture, lowest published configuration $149/month, 610 API credits/minute**. This is the cheapest researched plan explicitly advertising external display, not a confirmed all-inclusive quote. The default real US feed represents approximately 5% of executions, NOT consolidated SIP. Do not label its volume as total US market volume. Native 15min OHLCV and long intraday history make it a suitable technical fit. The official US article additionally requires a US equities redistribution add-on for client access; whether VOLTEX's cached JSON delivery falls within display versus redistribution and the add-on price is **unresolved**. Obtain written scope/retention/attribution confirmation before paying or enabling anything.

Concrete alternative: **Tiingo EOD + IEX Display Redistribution $250/month startup / $500 enterprise**, subject to startup eligibility and signed scope. $50 internal Commercial is NOT enough. IEX-only bars have venue volume; do not substitute derived reference prices for exchange OHLCV. Tiingo's current documentation says full TOPS requires an IEX agreement since February 2025; older 15ms delay notes do not override that. Any additional entitlement fees and historical retention need a written quote. An absolute cheapest all-inclusive legally licensed total cannot be established from the public documents alone.

A verified exposed block device enables direct-I/O proof at1MiB/s read /128KiB/s write; if unavailable, comparisons may still run, but the separate I/O evidence gate remains FAILED, never substituted by tmpfs.
4. Stocks was pinned to the SAME core as crypto AND PostgreSQL. Three-variant comparison before/after/separate-core holds quota .05vCPU256MiBzeroSwap constant. It measures placement effect, not permission to pin production API/DB.
5. Old readerSIGTERM discarded in-flight outcomes. New reader drains before fixture shutdown and categorizes errors; request cadence200ms, timeout3s and cursor workload unchanged.

Paired baseline uses stock implementation from integrationa9de4298; current financial implementation is identical in all variants.
