Проверялся собранный интерфейс, настоящий обработчик API и настоящий
локальный Worker с SQLite-хранилищем. Сценарий проверки пересоздаёт только
одноразовые тестовые данные. Внешние запросы и финансовые записи запрещены.

Пройдено 9 составных браузерных проверок: выбор всех сценариев,
некорректный промежуточный ввод, десятичные расчёты, сохранение параметров,
три периода свечей, устаревший предпросмотр, обработка ошибки, размеры
экранов, полное повторное открытие Worker, отдельное подтверждение
публикации и блокировка уже опубликованной истории.

Ранее существовавший полный браузерный сценарий листинга дополнительно
прошёл 20 проверок, включая прежние ограничения исполнения заявок.
Для обоих прогонов: ошибок страницы — 0, внешних запросов Worker — 0.

Проверка CI повторяет сценарии на последнем коммите PR. Её свежие отчёты
и снимки сохраняются отдельными артефактами GitHub Actions; эти файлы —
снимок локальной проверки, а не доказательство публикации на рабочем сайте.
