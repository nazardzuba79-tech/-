# Експорт даних графіка

## btcusd_bitstamp_1d_20261126.csv

- Символ: BITSTAMP:BTCUSD. Таймфрейм: 1 день.
- 5547 барів, з 2011-08-18 по 2026-11-26. Останній бар на момент збору ще не закрився (2026-11-26, близько 17:54 UTC), тому його значення не остаточні.
- 131 стовпчик: `time, open, high, low, close, volume`, далі значення кожного індикатора.
- SHA-256 файлу: `7fe7222dd60507456c0f073c4af0e5ea2d8428e71c4c53e1f2c878cfbb70926a`.

### Як зроблено

Штатний пункт «Експортувати дані графіка» в TradingView працює лише для збереженого макета. Щоб не створювати нічого в акаунті власника, індикатори поставлено на тимчасовий незбережений графік, історію дозавантажено до початку, а значення зчитано з цього графіка. Це ті самі числа, які TradingView показує в легенді та віддав би в штатному експорті, але назви стовпчиків складено тут.

### Назви стовпчиків

`Назва індикатора | назва лінії [тип]`. Типи:

- `line` — лінія зі значенням ціни або показника;
- `shapes` — позначка (стрілка, мітка): непорожнє значення означає, що на цьому барі позначка є;
- `alertcondition` — умова сповіщення: 1 означає, що умова спрацювала;
- `colorer`, `bg_colorer` — номер кольору лінії або фону. Що означає кожен номер, без коду достеменно невідомо.

Якщо автор не дав лінії назву, TradingView називає її `Plot`, `Shapes` або `Background Color`. Такі стовпчики йдуть у тому порядку, у якому їх малює індикатор.

### Індикатори у файлі

Volume, Opportunity, Nazar V1, Nazar V2, Pi Pi, div, GLOBAL, Pifagor_ALTS 3.7 strategy, Trader 01, bottomline, Trap line.

Усі з аргументами за замовчуванням.

### Застереження

- **Nazar V1** — стовпчики порожні: скрипт відмовляється працювати на BTCUSD Bitstamp.
- **GLOBAL, Pi Pi** — усі лінії порожні на цьому символі й таймфреймі; заповнені лише позначки, фон і сповіщення.
- **Значення закритих індикаторів могли бути перемальовані.** Файл показує історію такою, якою її видно сьогодні. Чи бачив би трейдер ті самі значення в реальному часі, із файлу не видно; це треба перевіряти окремо, спостерігаючи за живими барами.
- Стратегії (GLOBAL, Pifagor_ALTS) у файлі представлені лише своїми лініями та позначками, без списку угод.
