# CYCLE / REGIME / TACTICAL — результати (v1, 2026-09-22)

**Статус усіх трьох систем: RESEARCH-ONLY. Жодна не має підтвердженої переваги на холдауті. Не для торгівлі.**

Правила побудови — `docs/PREREGISTRATION.md`. Ваги не підбиралися (рівнозважене середнє причинних percentile-рангів зі знаками).
Дві версії на систему: `confirmed` (лише компоненти, що пройшли правило підтвердження на development) і `exploratory` (усі
pre-registered компоненти після дедуплікації сімей). Холдаут (рішення з 2023-01-31) відкривався **один раз**; після нього нічого не змінювалося.
Деталі: `systems/<name>/results.json`, `composite_*.csv`, `backtest_*.csv`.

## CYCLE (h=365, ціна Coin Metrics)
- `confirmed` = **один** компонент: M066 log power-law residual (O013 mcap/thermocap — та сама сім'я, ρ=0.98, відкинуто правилом дедуплікації).
- Development: IC 0.43 [90%: 0.07; 0.71], n=3091 (N_eff≈8.5); зрізи full 0.43 / ex_2020 0.29 / ex_2017 0.51; по роках від −0.74 (2016) до +0.97 (2017) — типова нестабільність при 1 спостереженні на цикл.
- Холдаут: IC 0.88, але n=965 днів → **N_eff≈2.6 < 8 → insufficient за протоколом**. Число наводиться, але не є підтвердженням.
- Backtest (експозиція = 1 − percentile, щотижня, 0.15%/сторона): dev CAGR 43.8% / vol 50% / Sharpe 0.73 / maxDD(log) −1.38 проти B&H Sharpe 0.52; baseline Mayer 0.42, MVRV 0.25. Холдаут: Sharpe 0.58 проти B&H 0.57 — **різниці немає**.
- `exploratory` (O072, M066, O067, O059, O081): dev IC −0.03 — гірше за один компонент; ablation показує, що O059 (fee share) і O072/O067 шкодять. O059 має сильний **протилежний** знак (−0.42) — це не переводиться у «переверни знак»; фіксується як гіпотеза для окремої майбутньої pre-registration.
- Чутливість: min_periods 730 → dev IC 0.42; витрати ×2 → Sharpe 0.73→0.73; OKX-ціна (2018+) dev IC 0.80 (менше вікно). Dropout джерела Coin Metrics → композит порожній (єдине джерело).
- **Висновок:** довгострокова «дорожнеча» відносно логарифмічного тренду має узгоджений напрям на 2013–2021, але доказова база — ~8 незалежних спостережень; холдаут неінформативний за побудовою. Це не «супер-індикатор», а один price-only показник з широкою невизначеністю. Онлайн-складники (MVRV, Puell, hash ribbons, exchange supply) **не** довели incremental value.

## REGIME (h=30, підтвердження на CM-ціні 2011–2022; виконувана перевірка на OKX)
- `confirmed` = O080 exchange balance Δ30 (−), M106 broad dollar Δ30 (−), O046 active addresses Δ30 (+), N004 spot volume Δ30 (+). O079 відкинуто як дублікат O080 (ρ=1.0).
- Development: IC 0.174 [0.08; 0.26], n=4520; зрізи 0.17 / 0.21 / 0.18, **since_2022 −0.07**. Ablation: жоден компонент не шкодить; single-component IC 0.03–0.13, композит 0.17 (є incremental value на development).
- Холдаут: **IC −0.12 [−0.25; −0.01]**, n=1300 (N_eff≈43) — **знак змінився**; по роках 2023 −0.10, 2024 −0.14, 2025 −0.02, 2026 −0.20. На OKX-ціні −0.12. Без FRED-компонента холдаут ≈ 0.00; без Coin Metrics −0.18.
- Backtest холдаут: Sharpe 0.45 проти B&H (масштабованого) 0.57; baseline SMA200 0.62. Development Sharpe 0.98 ≈ baseline SMA200 0.98 → композит **не кращий за простий тренд** навіть на development.
- `exploratory` (19 компонентів): dev 0.17, холдаут **−0.22** — ще гірше.
- **Висновок:** негативний результат. Слабкий development-ефект не відтворюється після 2022 (зміна розподілу: ETF-ера, інша структура біржових балансів). REGIME v1 не використовувати.

## TACTICAL (h=7, OKX-ціна 2018+, контртрендова гіпотеза)
- `confirmed` = **порожньо**. Жодна stretch-міра не має pre-registered (від'ємного) напряму на 7 днів.
- `exploratory` (N005, M018, M096t, M068 після дедуплікації): dev IC −0.07 [−0.16; 0.01] (тобто momentum), холдаут 0.00 [−0.11; 0.11]. Уmовний на тренді: в аптренді dev −0.13 / холдаут +0.02; у даунтренді +0.01 / −0.10 — нестійко.
- Backtest: dev Sharpe −0.16 (turnover 42/рік, витрати з'їдають), холдаут 0.08 проти B&H 0.56.
- Funding (97 днів), long/short (180), taker (72) — insufficient; у холдауті 1-денний IC funding +0.12 на 90 точках — шум.
- **Висновок:** контртрендова гіпотеза на денних даних BTC **спростована** в цьому дизайні; короткостроковий (7d) ефект, якщо є, — momentum, і він не був pre-registered, тож не заявляється.
