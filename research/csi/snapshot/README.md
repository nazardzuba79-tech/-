# CSI — дослідження 120 ринкових + 120 ончейн-кандидатів
Пакет для подальшої розробки CYCLE, REGIME і TACTICAL у Claude Code або Codex.
Дата дослідження: 21.09.2026. Документація українською; поля й код англійською.

**Ключова межа:** 240 кандидатів ≠ 240 завантажених рядів. У SQLite `series` **0 рядків**, raw market responses відсутні. Перший network probe повернув DNS failure на кожному з чотирьох обов’язкових доменів. Браузерний доступ використовувався лише для дослідження визначень/літератури, не для відтворення котирувань.

## Початок
Прочитайте `START_HERE_UA.md`, далі передайте агенту `PROMPT_BUILD_THREE_UA.txt`.
Не потрібно переносити окремі попередні ZIP чи документи. Два поточні оригінальні
ТЗ збережені в `inputs/` без редагування; старі неперевірені індикатори не включені.

## Що всередині
- `research/RESEARCH_UA.md`: висновки, сімейства, економічні гіпотези, обмеження доказів.
- `catalog/catalog.csv` та `.json`: 120 market + 120 onchain; всі задані колонки.
- `catalog/by_category/*.md`: повні людські картки кожного кандидата.
- `catalog/selection_metadata.json`: family, definition verification, provenance scopes.
- `catalog/SOURCES.md` і `sources.json`: 85 джерельних записів; 81 відкритий текст, 4 обмежені записи з явним статусом. Не 85 емпіричних досліджень.
- `research/SPEC_AUDIT_UA.md`: конфлікти/ризики постановки без прихованої зміни schema/lag.
- `research/MATHEMATICAL_REDUNDANCY.md`: точні тотожності та відмінність stock/flow.
- `research/AGENT_CHOICE_UA.md`: перевірені можливості агентів і умовна рекомендація.
- `collectors/`: первинний collector scaffold, preflight, exact schema, запити та перевірки.
- `data/csi.db`, `data/series.csv.gz`: **порожня схема та header-only backup**, не історія.
- `reports/`: фактичний network log, 73 неотримані core-пари, source status, порожні data-check reports, QA.
- `evaluation/SUMMARY.md`: протокол, оцінки НЕ виконані.
- `AGENTS.md`, `CLAUDE.md`, два промпти, `RUN_STATE.json`, `FILE_SHA256.csv`.

## Безпека й межі застосування
Даних для реальних угод немає. Не запускати торгові операції. Не потрібні wallet/API
trading keys чи production VOLTEX. Не завантажувати paid/trial providers, заборонені ТЗ.
Код не створює композитів, не оптимізує weights і не містить вигаданих результатів.
Якщо наступний агент не може отримати реальну історію, він не повинен будувати
«суперіндикатор» на порожніх чи підмінених входах.

Архів менше 1 МБ через відсутність котирувань; його не збільшували штучно. Для застосування
як data-пакета необхідно виконати наступний network/data gate. Дослідницька частина
придатна до аудиту й передачі незалежно від доступності мережі.
